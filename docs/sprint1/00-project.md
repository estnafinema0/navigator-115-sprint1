# 00. Навигатор-115: описание проекта

Версия от 27.10.2026. Команда Pulsar (ВМК МГУ) · «Академия Финтеха 2026», трек ВТБ «Финтех без границ».

## Что это

Сервис для ИП и микробизнеса, которым банк ограничил операции или прислал запрос по 115-ФЗ или 161-ФЗ, и инструмент для банка, который такие уведомления отправляет.

- **Клиенту любого банка:** вставляет текст запроса или уведомления и получает карточку меры, где у каждого поля есть цитата из текста банка; видит, что банк обязан был сообщить по письмам ЦБ; законные сроки по производственному календарю; допустимые пути обжалования (МВК только там, где она допустима); заявление по шаблону Банка России, заполненное фактами дела.
- **Банку (ВТБ):** страж уведомлений, то есть проверка текста до отправки клиенту на обязательные элементы (ИН-01-59/98, ИН-03-59/11) и на запрещённое (п. 6 ст. 7 115-ФЗ); структурированный запрос и пакет с описью (спринт 2).

## Проблема (кратко; подробно в `01-discovery.md`)

Жалобы в ЦБ на антифрод-меры банков выросли в 2,25 раза за 2025 год, в I кв. 2026 ещё на 45,2 % (ЦБ). Банки «зачастую не объясняли клиентам, в чём причина ограничений, и что делать» (М. Мамута, ЦБ). В 45 публичных текстах уведомлений норма закона указана в 16 % (95 % ДИ 8–29 %), срок в 22 % (13–36 %), МВК ни разу (наш корпус, предварительно).

## Как устроено

Ядро детерминированное: таймеры, маршрутизатор, чек-листы, страж, генераторы документов. Локальная российская модель (T-lite-it-2.1, on-prem) только извлекает поля из текста, и каждое поле обязано опираться на дословную цитату: без цитаты поле обнуляется. Нормы берутся из сохранённых первоисточников с датой редакции (`kb/sources/`).

## Граница

Не советуем, как обойти контроль; не меняем назначение платежей; не сочиняем пояснения; не обещаем разблокировку; не оказываем юридическую помощь. Регрессионный тест границы: `make attacks` (`reports/attacks-2026-10-27.md`).
