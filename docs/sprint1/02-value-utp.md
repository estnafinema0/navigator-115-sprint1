Ценность для бизнеса рациональная, как и просил ВТБ на открытии: «решения принимаются не эмоционально, а рационально, на выгодах» (О. Степанов, `context/research/v2/meetup-opening.md`, пересказ). Альтернатива клиента: юрист, ответ банку 15–25 тыс. ₽, жалоба в МВК 15–50 тыс. ₽ (`competitors-whitespace.md`, разд. 3).

## 4. Белые пятна и УТП

Публично не найдено ни у кого (`competitors-whitespace.md`, разд. 5): разбор запроса любого банка с цитатами; трекер законных сроков; маршрутизатор с допустимостью МВК; страж уведомлений; аналитика причин запросов.

**УТП в одной фразе.** Навигатор-115 работает с **уже пришедшим** запросом **любого** банка: каждое поле с цитатой из текста банка, сроки и маршрут по нормам с датой редакции, а для банка страж, который проверяет уведомление по письмам ЦБ до отправки.

**Почему не ChatGPT: эксперимент «против DIY» проведён 26.10** (`reports/diy-2026-10-27.md`). 20 дословных реальных текстов, промпт № 1 бухгалтерского гайда Клерка (05.08.2026), **та же локальная модель T-lite-it-2.1 без схемы и валидатора**. Облачный ChatGPT не проверяли: реальные тексты во внешние сервисы не отправляем.

| Что | DIY: та же локальная модель | Навигатор-115 |
|---|---|---|
| Утверждения или поля без дословной опоры в тексте банка | 215 из 264 (81 %) | 0 из 110 (выполняется по построению: поле без цитаты обнуляется) |
| Факты не из текста (нормы, даты, сроки, суммы, органы; без строки «закон») | 1 из 21 (5 %) | 0 из 19 |
| Ответов в виде таблицы, которую просит промпт | 0 из 20 (модель слабая, рассуждает вслух) | не применимо |

Главный аргумент здесь подмены сроков и маршрутов, которые клиент не заметит; «0 без цитаты» выполняется по построению и вторичен:
- **C1:** в тексте банка срока нет, DIY пишет «обычно это 5 рабочих дней»;
- **B9:** срок рассмотрения банком («обрабатываем в течение 3 рабочих дней») DIY выдал за срок клиента;
- **схема без валидатора:** та же модель со схемой дописала суд или Банк России как маршрут обжалования в 5 текстах из 20; валидатор снял все.

Ограничения: одна слабая локальная модель, короткие фрагменты, правила нашей стороны писались на этом же корпусе. Сильная облачная модель, скорее всего, выдаст таблицу и назовёт 7 р. д. по п. 13.4; тогда наши аргументы: ПДн не уходят во внешний ИИ, всё сверяется с письмом, маршрутизатор не выдаёт недопустимых маршрутов.

**Почему ядро без ИИ.** Таймеры, маршрутизатор, чек-листы, страж и генераторы: детерминированный код; LLM только извлекает поля с цитатой. Это совпадает с позицией ВТБ на открытии: интереснее решения, где ИИ не главное (`meetup-opening.md`).

## 5. Границы: чего не делаем

Не советуем, как обойти контроль; не меняем назначение платежей; не сочиняем пояснения и экономический смысл операций; не обещаем разблокировку; не оказываем юридическую помощь; при сложных случаях эскалация к юристу. Граница обеспечена конструкцией: в интерфейсе нет свободного чата, клиенту выдаются только цитаты из письма, сроки по норме и шаблоны ЦБ без доводов. Детектор запросов на обход (`api/navigator/intent.py`) проверяется регрессионным тестом `make attacks` (`reports/attacks-2026-10-27.md`: 47 из 47 атак фиксированного набора, 0 ложных отказов из 28). Набор использовался при настройке, поэтому это не доказательство обобщения: на 30 новых атаках красной команды отказ дан в 25 (83 %), ложных отказов 4 из 7 обычных вопросов (`jury/sprint1/redteam.md`).
