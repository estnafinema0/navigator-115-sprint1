# Навигатор-115

Разбор запросов и уведомлений банков по 115-ФЗ и 161-ФЗ для клиента любого банка: что за мера, какие документы собрать по пунктам запроса, законные сроки и допустимый маршрут обжалования. Для банка: страж уведомлений по требованиям ЦБ; структурированная приёмка пакета в плане на спринт 2.

Команда Pulsar (ВМК МГУ) · «Академия Финтеха 2026», трек ВТБ «Финтех без границ».

- Лицензии сторонних компонентов, моделей и данных: [`THIRD_PARTY_LICENSES.md`](THIRD_PARTY_LICENSES.md)

## Принцип

Ядро продукта детерминированное: таймеры по производственному календарю, маршрутизатор с правилами допустимости, чек-листы, страж уведомлений. LLM (локальная, российская, on-prem) только извлекает поля из текста банка, и **каждое поле обязано опираться на дословную цитату**: поле без цитаты валидатор обнуляет и показывает как «не указано банком». Нормы берутся из версионированной базы `kb/` с первоисточником и датой редакции, не «из памяти» модели.

Продукт никогда не советует, как обойти контроль, не переформулирует назначение платежа, не сочиняет экономический смысл операций и не обещает разблокировку. Решение всегда принимает человек.

## Быстрый старт (сейчас)

```bash
make setup         # venv + зависимости (Python ≥3.11)
make check         # линтер, тесты, проверка gold-разметки
make corpus-stats  # отчёт по корпусу → reports/corpus-compliance.md
```

Публичный стенд (Yandex Cloud, без модели, разбор правилами): https://d5d6vupgj94sc8tf29t2.s183zexc.apigw.yandexcloud.net. Обновление: `infra/yc-function/README.md`.

Демо и проверка качества:

```bash
make demo          # docker compose: api + db + ollama; первый запуск качает T-lite-it-2.1 (~5 ГБ) → http://localhost:8000
make web           # собрать веб-интерфейс в web/out (Node ≥20.9); make demo собирает его сам
make demo-local    # без Docker: нужен локальный Ollama с моделью hf.co/t-tech/T-lite-it-2.1-GGUF:Q4_K_M
make synth         # синтетика с эталоном → data/synthetic/
make eval PREDICTOR=rules            # rules | hybrid | llm | gold | empty → reports/
```

API: `/api/v1/parse`, `/api/v1/deadlines`, `/api/v1/routes/{scenario}`, `/api/v1/documents/{1|4|5}`, `/api/v1/guard` (описание в `/docs`). Веб-интерфейс в `web/` (Next.js, дизайн `design/DESIGN.md`) собирается в статику `web/out`, и её раздаёт тот же FastAPI: разбор письма, сроки и маршрут, заявление, страж уведомлений. Без сборки раздаётся старое демо `web-legacy/`. Для разработки интерфейса: `cd web && npm run dev` (порт 3115, запросы `/api` уходят на API на порту 8115).

## Структура

| Путь | Что |
|---|---|
| `api/schema/bank_request.schema.json` | контракт извлечения M1: 12 сценариев триажа, меры, основание, перечень, сроки, каналы, обжалование; у каждого поля цитата |
| `api/navigator/` | ядро: `evidence.py` (поиск цитат), `validator.py` («нет цитаты, нет поля») |
| `data/real/corpus.jsonl` | корпус 45 публичных текстов уведомлений банков (обезличено), разметка E1–E9 |
| `data/synthetic/` | синтетика (каждый объект помечен «синтетика») |
| `web/` | веб-интерфейс (Next.js, статический экспорт); `web-legacy/`: первое статическое демо |
| `design/` | DESIGN.md (утверждён, G9), журнал решений, отчёт Delivery Gate и скриншоты |
| `eval/gold/` | эталонная разметка по схеме (сейчас 3 черновика на проверку кодировщиками) |
| `kb/` | база норм: первоисточники (`kb/sources/`), нормы, производственный календарь |
| `reports/` | отчёты: корпус, eval, ежедневные отчёты капитану |
| `interviews/` | гайд и шаблоны проблемных интервью (записи и расшифровки в репозиторий не коммитим) |
| `scripts/` | сборка корпуса, проверка gold, статистика |
| `context/` | ресерч и история проекта (не код продукта) |

## Ограничения на 27.10.2026

- Работают: разбор (правила + локальная LLM + валидатор цитат), сроки по календарю 2026–2027, маршрутизатор, генераторы заявлений по шаблонам ЦБ № 1, 4, 5, страж на правилах. Веб-интерфейс работает на API (проверка 26.10: `design/gate-sprint1.md`); `docker compose` и сборка образа не проверены на этой машине (Docker не запущен).
- Точность разбора на реальных текстах **не измерена**: нужна gold-разметка людьми (n ≥ 20). На синтетике метрики завышены: шаблоны синтетики и правила писал один автор. «Додуманные» поля на синтетике 0,05 при пороге 0,02 (`reports/eval-2026-10-27-hybrid-tlite.md`).
- Скорость разбора на ноутбуке MacBook M1 16 ГБ, T-lite-it-2.1 Q4_K_M: медиана 18,6 с, p95 61,5 с (n = 39, `reports/eval-2026-10-27-hybrid-tlite.md`). API ждёт модель не дольше 90 с, затем разбирает правилами и показывает это пользователю.
- Страж на правилах: на отложенном наборе 27.10 (25 синтетических фраз жюри и красной команды) до правок поймал 1 из 22 запрещённых, после правок все; правила дописаны по этим фразам, поэтому набор больше не отложенный (`reports/guard-2026-10-27.md`). Замер на реальных уведомлениях, размеченных ПОД/ФТ, не проведён.
- Детектор запросов на обход: 47 из 47 атак и 0 ложных отказов из 28 на фиксированном наборе (регрессия, `reports/attacks-2026-10-27.md`); новые атаки из протоколов добавлены в набор после правок, на 12 новых атаках жюри-агента (раунд 2), по которым правила не дописывали, отклонено 4 из 12, страж поймал 2 из 11 новых запрещённых формулировок (`jury/sprint1/score-r2-risk-compliance.md`). Правила ловят лексику, а не смысл.
- Эксперимент «против DIY» проведён на одной локальной модели, облачные модели не проверялись (`reports/diy-2026-10-27.md`).
- Корпус: 45 публичных текстов из отзывов и публикаций (из них 19 пересказы клиентов; один кодировщик), смещён к конфликтным случаям; по ВТБ 1 текст. Это не аудит банков.
- Gold: 3 черновика, ещё не проверены людьми; согласие двух кодировщиков (κ) не посчитано.
- Маскирование на входе API: ИНН, счета, карты (проверка Луна), паспорт, дата рождения, телефоны, СНИЛС, e-mail (`api/navigator/pii.py`); ФИО и адрес регулярками не маскируются, пользователя просят удалить их до вставки текста. Аутентификации у API нет: это демо.
- Данных ВТБ нет и не будет: интеграции с банком только моки и sandbox.
- Интервью, анкет и пользователей пока нет (0 / 0 / 0); цифры о них не публикуем, пока не измерены. Все числа проекта с источниками: `docs/sprint1/numbers.md`.
